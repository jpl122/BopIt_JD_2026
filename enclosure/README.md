# DJ Bop-It Enclosure — Team Eta

3D-printed enclosure designed in Autodesk Fusion for our DJ Bop-It game.

## Files

- `DJ_BopIt_Team_Eta_Final.stl` — Assembly model.
- `BOM/BOMScrews.csv` — Purchased hardware list. M3 hardware is supplied by SERC.

## Features

- Horizontal slide potentiometer
- Jog wheel
- Tilted OLED mount
- Start button
- Extended capacitive keyboard tray
- Speaker grille
- Removable bottom cover
- Team Eta engravings

## Printing

Prepare the enclosure parts in Cura using millimeters and
100% scale. Use the lab’s approved PLA printer profile.

Check the layer preview and exclude electronics reference
geometry from the print job.

## Assembly

1. Remove supports and clean the mounting holes.
2. Test-fit the electronics and controls.
3. Install the mounting hardware and route the wires.
4. Attach the bottom cover last.

Fader and OLED board mounting screws still need confirmation
against the physical components.
